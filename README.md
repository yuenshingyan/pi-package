# My Pi Package

Shared pi extensions and skills.

## Contents

### Extensions
- **session-remove** — Interactive TUI for selecting and deleting past sessions (`/remove` command)

### Skills
- **code-sweep** — Sweep for logical fallacies, inefficiencies, concurrency bugs, and more
- **subagents** — Spawn parallel sub-agents for delegated tasks
- **web-search-usage** — Web search usage instructions

## Install

```bash
pi install git:github.com/YOUR_USERNAME/pi-package
```

## Note

The npm packages `pi-web-access` and `@plannotator/pi-extension` are installed separately:

```bash
pi install npm:pi-web-access
pi install npm:@plannotator/pi-extension
```
